# 설정 화면 다시 배치하기 (짧은 설계)

시안: [2026-11-23-settings-layout-mockup.html](2026-11-23-settings-layout-mockup.html). 브라우저로 열면 오른쪽 아래 [시안 상태]에서 결과 없음, 녹화 중, 세로 GIF, 긴 안내문, 밝게·어둡게를 바꿔 볼 수 있습니다.

## 왜

midi 창은 두 가지로 엽니다. 가끔 녹화 설정을 바꿀 때, 그리고 방금 녹화한 결과를 확인할 때입니다. 지금 화면은 560px 폭 한 줄에 모든 항목을 쌓아서, 720×600 창에서 스크롤해야 끝까지 보이고, 미리보기는 맨 아래에 붙습니다. 사용자는 한눈에 보이게 하고 싶어 하고, 글씨가 지금(15px)보다 조금 작아져도 된다고 했습니다.

## 목표, 하지 않을 것

- 목표: 720×600 창에서 페이지 스크롤 없이 설정 전체와 녹화 결과가 보임. 녹화 결과는 위에 크게.
- 하지 않을 것: 설정 항목이나 동작을 바꾸지 않음(배치와 문구만). 편집 기능은 만들지 않음.
- 실패로 볼 것: 지금 되던 동작(설정 저장, 조건부 칸, 녹화 시작·취소, 단축키 바꾸기, 자동 실행, 폴더에서 보기)이 하나라도 깨지는 것.

## 배치안 (고른 과정)

네 모델이 같은 조건으로 시안을 만들었고, 모두 720×600에서 스크롤 없이 맞았습니다.

| 배치 | 장점 | 단점 |
|---|---|---|
| **위 결과·아래 설정 (고름)** | 가로로 긴 GIF가 가장 크게 보임(약 452×240). 설정 7개가 두 열로 한 번에 보임 | 세로 GIF는 작아짐. 설정이 늘 아래 약 286px를 차지 |
| 왼쪽 설정·오른쪽 결과 | 세로 GIF에 유리(약 376×400). 긴 문구가 오면 미리보기가 줄어들어 받아 줌 | 설정이 좁은 한 열이라 세로로 김 |
| 두 칸에 고정 크기 미리보기 / 한 열 + 작은 미리보기 | | 미리보기가 작거나(190~135px 높이) 넘침을 숨기기만 함 |

사용자가 "위 결과·아래 설정"을 골랐습니다. 이것을 기준으로 다른 시안에서 옮긴 것: 설정 묶음 제목(녹화 / GIF / 앱), 미리보기를 픽셀 그대로 선명하게(`image-rendering: pixelated`, 지금 앱의 방식). 숫자 칸을 넓히는 것은 "가로×세로 지정" 선택칸이 잘려서 되돌렸습니다(지금 폭으로도 4096이 다 보임).

## 정한 것

- 머리줄: 제목 "GIF 만들기", 단축키 안내(`#hotkey`), 오른쪽에 [● 녹화 시작](`#record`)과 녹화 중에만 [✕](`#cancel`).
- 결과 줄(남는 높이 전부): 왼쪽 미리보기(`#preview`, 체크무늬 위에 비율 유지). 결과가 없으면 같은 자리에 "아직 녹화한 GIF가 없습니다"(CSS만으로, `#preview[hidden]`). 오른쪽 232px "녹화 결과" 칸: 상태(`#status`), 인코딩 정보(`#encoded`), 저장 경로와 [폴더에서 보기](`#saved`).
- 설정 판(아래): 두 열. 왼쪽 "녹화": 프레임 수, 영역 정하기, 녹화 시작, 크기. 오른쪽 "GIF": 화질 단계, 용량 목표, 디더링, 그 아래 "앱": 녹화 단축키, 자동 실행. 라벨 왼쪽·입력 오른쪽 한 줄, 안내 문구는 입력 아래.
- 글씨 13px, 안내 12px, 제목 14px. 밝은·어두운 테마 둘 다.
- 폼(`#settings`)은 녹화 설정만 감쌈. 단축키와 자동 실행은 지금처럼 폼 밖이라 바꿔도 녹화 설정 저장(`remember_settings`)이 돌지 않음.
- id는 지금 것을 모두 유지하고, [샘플 만들기](`#make`)와 머리말 설명은 뺌.

## 만드는 사람에게 맡기는 것 (내가 정한 것 포함)

- **긴 문구:** 디스크 여유 공간 부족 안내처럼 드문 긴 상태 문구는 "녹화 결과" 칸이 넘칠 수 있습니다(시안에서 가장 긴 문구를 다 넣으면 103px 넘침). 그때는 그 칸 안에서만 스크롤되게 둡니다(페이지는 스크롤 없음). 내 판단입니다. 보통 문구(용량 목표 2MB 결과 등)는 넘치지 않습니다.
- **main.js 정리:** `make` 관련 줄과 폼 submit 처리를 지움. 시안용 값·`[시안 상태]`·데모 스크립트를 지우고 `hidden` 기본값을 지금 페이지대로 되돌림. 프레임 수 선택지의 "15 fps"처럼 바뀐 문구는 값(`value`)이 그대로라 저장된 설정과 맞음.
- **확인:** 실제 앱(개발 빌드)을 720×600으로 띄워 결과 있음·없음·녹화 중에 스크롤이 없는지, 설정을 바꾸면 저장되고 다시 켜도 남는지, 조건부 칸(크기 지정, 용량 직접 입력, 녹화 틀 안내)이 지금처럼 나타나고 사라지는지 봅니다.
